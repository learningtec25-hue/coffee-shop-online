# Brew & Bloom Coffee

A responsive online coffee shop storefront built with semantic HTML, custom CSS, and vanilla JavaScript.

## Features

- Responsive café-inspired layout
- Product menu with category filters
- Add-to-cart, quantity controls, and dynamic totals
- Cart persistence with `localStorage`
- Checkout form validation and order confirmation state
- No build tools or dependencies required

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.

## Customize

Edit the product list in `js/app.js`, update shop details in `index.html`, and adjust colors in `css/styles.css`.

This is a frontend demo. Connect the checkout form to a secure backend/payment provider before accepting real orders or payments.
